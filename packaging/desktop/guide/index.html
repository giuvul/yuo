Installing Yuo on your computer

Yuo runs on your own computer. You double-click one file; a window opens, installs what Yuo needs (about 400 MB, a few minutes the first time) and then opens Yuo in your browser. You never type a command.

Yuo is free software and is not signed with a paid certificate yet, so Windows and macOS warn you the first time. This page shows what you will see and what to click. Everything Yuo installs goes into one folder in your user account; nothing is installed for other users.

Windows 10 and 11

  1. Unzip the download: right-click it, Extract All…, Extract.
  2. Open the extracted folder and double-click Yuo-Windows (or Yuo-Windows.bat).
  3. Windows asks:
    Open File - Security Warning. The publisher could not be verified. Are you sure you want to run this software?
    Click Run. If you see "Windows protected your PC" instead, click More info, then Run anyway.
  4. A black window opens and shows what it is doing. Keep it open while you use Yuo; closing it stops Yuo.
  5. Your browser opens Yuo. Next time, double-click Yuo-Windows again; it starts in seconds.

Smart App Control

On some new Windows 11 computers Smart App Control is on. It blocks programs that have no signature, including the Python that Yuo installs, and it offers no "Run anyway". The window then says Smart App Control is on, or Yuo stops with "An Application Control policy has blocked this file".

  1. Open Windows Security > App & browser control > Smart App Control settings.
  2. Choose Off only if you are comfortable doing so: it protects against unknown programs in general. On recent Windows 11 versions you can turn it on again later.
  3. If you prefer to keep it on, Yuo cannot run on this computer yet; a signed version is planned.

macOS (Apple silicon: M1 or later)

Not yet tested on a real Mac. Intel Macs are not supported: some parts Yuo uses are not built for them.

  1. Double-click the download to unzip it, then double-click Yuo-macOS.command.
  2. macOS says the file cannot be opened because Apple cannot check it. Click Done (not Move to Trash).
  3. Open System Settings > Privacy & Security, scroll down, and next to the message about Yuo-macOS.command click Open Anyway. Enter your Mac password if asked.
  4. Double-click Yuo-macOS.command again and click Open. A Terminal window opens and runs by itself; you do not type anything. Keep it open while you use Yuo.

Linux

  1. Unzip the download and open the folder.
  2. Double-click Yuo-Linux.sh. If your file manager opens it as text, right-click it, choose Properties > Permissions and allow executing as a program, or choose Run as a Program.
  3. After the first start Yuo is also in your applications menu.

Where your things are

  • Windows: %LOCALAPPDATA%\Yuo · macOS: ~/Library/Application Support/Yuo · Linux: ~/.local/share/yuo-desktop
  • Your learning data is in its data folder, with a checked backup every day in data/backups.
  • If something goes wrong, logs/launcher.log in the same folder says what happened.
  • Yuo listens only on this computer (address 127.0.0.1); nothing on your network can reach it.

Updates

Yuo looks for a new version once a day (you can turn this off in Settings). When there is one, Settings offers to download it; Yuo checks the download against the published checksum and installs it the next time it starts. Before the new version changes your data it makes a backup; if the new version does not start, Yuo puts your data back and runs the previous version.

For technical users: checking the download

Each release lists the SHA-256 of the zip in SHA256SUMS. The launcher downloads uv from its official GitHub release and checks it against a hash written in the launcher; Python comes from uv's managed builds and Yuo's dependencies are installed with --require-hashes from the release's lock.
